An example - configuring it

export const PLAYGROUNDS_URL = new InjectionToken<string>('Playgrounds URL', {  providedIn: 'root',  factory: () => 'assets/copenhagen.json'});

An injection token with default implementation

export const PLAYGROUNDS_URL = new InjectionToken<string>('Playgrounds URL');

Just an injection token

providers: [  {    provide: PLAYGROUNDS_URL,    useValue: 'assets/aarhus.json'  }]

Add to an injector (Or override the default implementation)

So the first example is not provided anywhere The second example is provided in root, and can therefore be used everywhere The last either provides the injectiontoken or overrides the exsisting provided value
