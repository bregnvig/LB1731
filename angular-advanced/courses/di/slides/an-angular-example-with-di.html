An angular example - with DI

@Component({})
export class WithDIComponent {

  #locationService = inject(LocationService);
  playgrounds$ = inject(AarhusPlaygroundService).playgrounds$;
  location$ = this.#locationService.location$;

}
The great thing about doing it like this is that we automatically gets the types directly from the services Notice # - the real javascript private. Which is why we prefer this way now
