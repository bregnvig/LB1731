1. The preferred way

@Injectable({
  providedIn: 'root'
})
export class MyService {
  
}

This service will be available to every and all components, services and pipes in your application. The reason? It's defined at root level!

This means that even though it has been defined in a lazy module, the service will be added to the application wide injector. Which is SUPER cool and done by webpack/esbuild There are other options than root. Type<any> = Used for modules - deprecated in v15 'root' = Everyone everywhere 'platform' = A special singleton platform injector shared by all applications on the page. 'any' = Provides a unique instance in each lazy loaded module while all eagerly loaded modules share one instance. This option is DEPRECATED. - deprecated in v15
