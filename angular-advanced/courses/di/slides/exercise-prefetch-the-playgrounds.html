Exercise - Prefetch the playgrounds

If not happy with the solution to exercise 2? Then goto the the labs/di/exercise-3 directory

In the main.ts add a provideAppInitializer to prefetch the playgrounds.

Do that by returning the playgrounds$ observable from the PlaygroundService.

Now check the network traffic. Notice the playgrounds are being fetched more than once!

So change the unicast observable in the playgrounds service, to a multicast, that will use the cached result. Remember multicast from the RxJS module?

It will be hard to see the difference, so try to add a timer(2000).pipe(switchMap...) in the provideAppInitializer function to see how the application take a long time to load.

We can use promises, since the observable would need to be complete, and there for we would never receive new playgrounds anyways.
