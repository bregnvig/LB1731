An angular example - without DI

@Component({})export class WithoutDIComponent implements OnInit {   playgrounds$: Observable<Playground[]> | undefined;  location$: Observable<Coordinate>;   #service: PlaygroundService;   constructor() {    this.#service = new AarhusPlaygroundService();    this.location$ = new LocationService().location$;  }   ngOnInit(): void {    this.playgrounds$ = this.#service.playgrounds$;  }}
What if AarhusPlayground services has dependencies? Actually, what if it need the HttpClient. That might be hard to get. (It actually is..) And that is one of key the points! You should not care about how to create it Nothing is shared! We create a new instance of the aarhus and location service with every component What if I want to use another service? (E.g the playgrounds service) Show that it is not possible because of the HttpClient!
