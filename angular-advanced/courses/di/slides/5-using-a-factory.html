5. Using a factory

const randomServiceFactory = () => {
  const http = inject(HttpClient);
  const userService = inject(UserService);
  return userService.user.isAuthorized
    ? new SomeBackendBasedRandomService(http) 
    : { random: 42 }
  );
};

providers: [{
    provide: RandomService,
    useFactory: randomServiceFactory,
}]

Factory methods are called once! 🤔

When used it is often in an APP_INITIALIZER situation. APP_INITIALIZER has since been deprecated as we now use the provideAppInitializer
