Injector DESTRUCTION💀

  • A provided dependency lives as long as the injector. Which means, that if we provide a dependency in the application wide injector or a route injector, they will never go away.
  • But what about components? Components goes away, and so does the injector!

This means DestroyRef/ngOnDestroy also works for services!🤯

But will never be called on the application wide or lazy loaded level

We will se this later in the example with injector levels
