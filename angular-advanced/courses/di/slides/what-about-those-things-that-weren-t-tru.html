WHAT ABOUT THOSE THINGS THAT WEREN'T TRUE?

optional - If it is alright it's not there

export class RandomComponent {
  service = inject(RandomService, { optional: true });
}

skipSelf - Go find it somewhere. Just not here!

export class RandomComponent {
  service = inject(RandomService, { skipSelf: true });
}

self - Needs to be provided here

export class RandomComponent {
  service = inject(RandomService, { self: true });
}

host - Needs to be provided here or parent when using projection 

export class RandomComponent {
  service = inject(RandomService, { host: true });
}
Let's play with these in the random example. Notice how the second number in the first three are the same -> @SkipSelf The first value are unique as they uses @Self The last two are wrapped, and receives the Random service from the component that wraps them. Notice how the second random is the same for the wrapped components? That because we walk up the tree and takes the first one
