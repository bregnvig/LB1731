An angular example - with DI prior to v14

@Component({})
export class WithDIComponent {

  playgrounds$: Observable<Playground[]> | undefined;
  location$: Observable<Coordinate> | undefined;

  constructor(locationService: LocationService, service: AarhusPlaygroundService) { 
    this.playgrounds$ = service.playgrounds$;
    this.location$ = locationService.location$;
  }

}
The client (the component) doesn't need to know how to construct the dependencies The services are reused amongst other components. I.e share state. How would you do that otherwise?
