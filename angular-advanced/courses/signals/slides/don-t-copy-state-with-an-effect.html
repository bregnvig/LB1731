Don't copy state with an effect

The effect runs later, during change detection. Until then, code reads a stale copy

Two sources of truth, an extra change detection pass, and a risk of loops

The screen looks fine. The code doesn't

Derived: computed
Derived, but writable: linkedSignal

firstName = signal('Ada');
lastName = signal('Lovelace');

// Derived: always in sync
fullName = computed(() => `${this.firstName()} ${this.lastName()}`);

// Anti-pattern: a copy kept up to date by an effect
fullNameCopy = signal('');
constructor() {
  effect(() =>
    this.fullNameCopy.set(`${this.firstName()} ${this.lastName()}`));
}

rename() {
  this.firstName.set('Grace');
  this.fullName();      // 'Grace Lovelace'
  this.fullNameCopy();  // still 'Ada Lovelace'
}
