Resource Api - The RESOURCEREF

Same interface, different creators. Let's take a look at that!

All resource functions

rxResource(), httpResource(), and resource() 

return a ResourceRef. Stable since v22.

It’s a signal-based object that exposes:

value(),  isLoading(), reload(),  error() and much more.

status(): idle, loading, reloading, resolved, error or local

// class
const user = resource(...);

// template
@if (user.isLoading()) {
  <spinner/>
} @else if (user.hasValue()) {
  {{ user.value() }}
}
value() throws while the resource is in error, so guard it with hasValue() (or check error() first). idle: params returned undefined, nothing loaded yet (e.g. no user selected). local: you called set() or update() on the value yourself.
