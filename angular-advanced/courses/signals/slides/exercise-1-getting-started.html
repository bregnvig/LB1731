Exercise 1 - Getting started

Begin by changing directory to labs/signals/exercise-1 and run npm install 
When complete, start the application using npm start

Allow location access when the browser asks: the app waits for your location before it shows anything.

The exercise focuses on improving performance by caching playground data in localStorage to avoid delays caused by a slow backend.

You will also use signals and an effect to save and retrieve playground data using localStorage, converting arrays to strings and back.

App waits for browser location. Blocked it? "Determining your location" forever: reset the site permission. After the exercise: "Don't copy state with an effect" (/signals/computed-vs-effect), then linkedSignal.
