Effect Cleanup

@Component({...})
export class SearchComponent {
  query = signal('');

  constructor() {
    effect(onCleanup => {
      const query = this.query();
      const timer = setTimeout(() => this.search(query), 300);
      // Before the next run, and when it's destroyed
      onCleanup(() => clearTimeout(timer));
    });
  }
}

Example:

Cancel what the previous run started: a timer, a request, a subscription. Here: only search when the user stops typing.

Type fast: every keystroke clears the previous timer, so only the last query is logged. Cleanup is for cancelling, not for remembering the previous value: that's linkedSignal's long form, a few slides back. v22 has debounced(signal, 300) for exactly this (experimental), and resources cancel their own requests.
