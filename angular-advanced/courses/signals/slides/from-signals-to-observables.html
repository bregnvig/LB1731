From Signals to observables

import { toObservable } from '@angular/core/rxjs-interop';

filterControl = new FormControl('');
playgrounds = input.required<Playground[]>();

filter$ = this.filterControl.valueChanges;
playgrounds$ = toObservable(this.playgrounds);

filteredPlaygrounds$ = combineLatest([
  this.filter$,

Creating an Observable from a signal

Use toObservable() to create an Observable which tracks the value of a signal.

Can only be created in an Injection context

Behind the scenes it's a ReplaySubject wrapped in an effect()

Same demo: demo/src/app/signals/playgrounds/playgrounds.component.ts. Emits asynchronously (via an effect): several sets in the same tick give one emission with the latest value.
