Signal Equality Functions

Determine whether a new value is different from the previous one

import { computed, signal } from '@angular/core';

const sameJson = (a: unknown, b: unknown) =>
  JSON.stringify(a) === JSON.stringify(b);

const playgrounds = signal([{name: 'Naturlegepladsen'}]);

// A computed signal with a custom equality function
const names = computed(
  () => playgrounds().map(p => p.name),
  { equal: sameJson }
);

// New array, same content: names does not change
playgrounds.set([{name: 'Naturlegepladsen'}]);

// Different content: names changes
playgrounds.set([{name: 'Hoppeborgen'}]);

Example:

You want to create a Signal that tracks changes in an array but considers two arrays equal if they have the same contents, even if they are different instances

signal(), computed() and toSignal() all take an equal option

Default equality is Object.is: a new array is always a change, even with the same content. Demo: /signals/equality (demo/src/app/signals/equality/playgrounds-equality.component.ts). toSignal refetches every second. Watch the console: without equal the shared list logs every second; uncomment the equal line and it stops.
