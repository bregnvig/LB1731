Signal Equality Functions

Determine whether a new value is different from the previous one

import { signal } from '@angular/core'; const equalPlaygrounds = (a, b) => 	JSON.stringify(a) === JSON.stringify(b); const playgrounds = signal([{name: 'Naturlegepladsen'}]); // A computed signal with our custom equality functionconst changedPlaygrounds = computed(  () => this.playgrounds,   { equal: equalPlaygrounds }) // No change in changedPlaygroundsplaygrounds.set([{name: 'Naturlegepladsen'}]);  // changedPlaygrounds has changedplaygrounds.set([{name: 'Hoppeborgen'}]);

Thus, the Signal's value is only considered different if the contents of the array change, even if the array instances themselves are different. This strategy is especially useful when you're working with complex data structures, such as arrays of objects or nested structures, and you want to trigger updates only when the data content changes, not when the reference to the data changes.
