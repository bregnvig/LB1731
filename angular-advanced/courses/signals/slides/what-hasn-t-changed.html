What Hasn’t Changed

Some decorators haven’t been migrated to signals:

  • @HostListener
  • @HostBinding / "host" (from @Component metadata)

 

These are the same as before. But do prefer to use the host element from the @Component metadata

@HostListener('click')
onClick() {
  this.toggle();
}
---
@Component({
  ...
  host: {
    class: 'bg-primary',
    '(mouseover)': 'fancyBackground()',
    '[class.active]': 'isActive()',
  }
  ...
})
host metadata gets type completion.
