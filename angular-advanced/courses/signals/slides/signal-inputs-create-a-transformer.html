Signal inputs - Create a transformer

You can easily create your own transformer!

const sortByName = (playgrounds: Playground[]) => playgrounds.slice().sort((a, b) => a.name.localeCompare(b.name));

@Component({...})
export class PlaygroundsComponent {

  // sorted list of playgrounds
  playgrounds = input.required<Playground[], Playground[]>({ transform: sortByName })
  
}
<app-playgrounds [playgrounds]="playgrounds()" />
A transformer is a plain function: what the parent passes in, what the component keeps. Here: always sorted. Keep it pure and cheap: runs on every input change.
