From Observables to Signals

import { toSignal } from '@angular/core/rxjs-interop';

@Injectable({...})
export class PlaygroundService {
              
  readonly playgrounds = toSignal(
    inject(HttpClient).get<Playground[]>('assets/copenhagen.json'),
    { initialValue: [] }
  );        
}

Stable since v20

Creating a signal from an Observable  using toSignal() creator function

Remember that signals created with toSignal() always subscribes immediately and are not writable

Can only be created in an Injection context

The value is undefined until the first emit, unless you give initialValue or requireSync: true

If the observable errors, reading the signal throws

(BehaviorSubject) Where you use async pipe today, consider toSignal(). Unsubscribes when the injection context is destroyed. requireSync for sync emitters (BehaviorSubject): no undefined in the type.
