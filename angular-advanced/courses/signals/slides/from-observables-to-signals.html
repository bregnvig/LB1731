From Observables to Signals

import { toSignal } from '@angular/core/rxjs-interop';

@Injectacble({...})
export class PlaygroundService {
              
  readonly playgrounds = toSignal(
    inject(HttpClient).get<Playground[]>('assets/copenhagen.json'),
    { initialValue: [] }
  );        
}

Stable since v20

Creating a signal from an Observable  using toSignal() creator function

Remember that signals created with toSignal() always subscribes immediately and are not Writeable

Can only be created in an Injection context

When using the async pipe on an observable consider using toSignal() instead.

Results memoized, meaning the value is calculated only when needed, and shared between all consumers
