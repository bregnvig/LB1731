From Zone.js to zoneless

  • Zone.js patches browser events, timers and promises, and checks components after every one
  • It only knows something might have changed 🤔
  • Since v21, new apps are zoneless: signals tell Angular exactly which views to update
  • The course apps still opt in to Zone.js
// app.config.ts in the course apps
providers: [
  provideZoneChangeDetection(),
  ...
]

// A new app since v21: nothing.
// Zoneless is the default.
Zone.js patches setTimeout, addEventListener, promises and runs change detection after each. It knows something async finished, not that state changed. Zoneless: Angular is told about changes: signal read in a template, template event, async pipe, markForCheck. Short version only; full change detection is in the Components module. Interactive comparison: https://jeanmeche.github.io/angular-change-detection/
