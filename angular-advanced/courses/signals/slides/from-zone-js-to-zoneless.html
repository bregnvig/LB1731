From Zone.js to zoneless

  • Zone.js patches browser events, timers and promises, and checks components after every one
  • It only knows something might have changed 🤔
  • Since v21, new apps are zoneless: signals tell Angular exactly which views to update
  • The course apps still opt in to Zone.js
// app.config.ts in the course apps
providers: [
  provideZoneChangeDetection(),
  ...
]

// A new app since v21: nothing.
// Zoneless is the default.
Zone.js monkey patches setTimeout, addEventListener, promises... and runs change detection after each one. It doesn't know whether state changed, only that something async finished. Zoneless: change detection runs when something tells Angular it changed: a signal read in a template, an event in a template, async pipe, markForCheck. Change detection itself is covered in the Components module; this is the short version. Interactive comparison: https://jeanmeche.github.io/angular-change-detection/
