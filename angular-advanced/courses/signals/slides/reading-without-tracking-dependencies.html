Reading without tracking dependencies

Access a Signal's value without creating a dependency

import { ..., untracked } from '@angular/core';

@Component({...})
export class UserLocationComponent {
  user: Signal<User> = ...;
  location: Signal<Coordinate> = ...;
  http = inject(HttpClient);

  constructor() {
    effect(() => {
      const location = this.location();
      const user = untracked(() => this.user());
      this.http.post(`api/location/${user.id}`, location)
        .subscribe();
    });
  }
}

Example:

You want post the users location everytime it changes, but not when the user changes (eg. a profile change).

Kinda like withLatestFrom (RxJS): location triggers, user is just read. Back to the infinite-loop demo: reading playgrounds with untracked stops the loop. But that only hides the problem. The real fix comes after exercise 1: don't use an effect to update state at all.
