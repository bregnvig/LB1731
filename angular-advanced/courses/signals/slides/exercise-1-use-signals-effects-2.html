Exercise 1 - Use Signals & effects

We see the loader because our backend is slow! So let's cache the playgrounds and show the ones we fetched last time right away.

Use an effect to save the playgrounds in the localStorage. You will need to use setItem & getItem from the localStorage.

Only save when there are playgrounds: until the backend answers, the signal is undefined, which isn't JSON. Blank page after a reload? Clear localStorage in DevTools.

localStorage only saves strings: JSON.stringify the array when saving, JSON.parse it when reading.

Finally initialize the playgrounds signal with data from localStorage
Bonus: delete changeDetection: ChangeDetectionStrategy.Eager from HomeComponent (AppComponent is optional). OnPush is the default and works with signals.

Solution (step-2) only saves when playgrounds is defined. Without the guard: reload during the 3 s load stores "undefined", JSON.parse throws, app stays blank until localStorage is cleared (DevTools > Application > Local storage).
