Writable signals

import { signal, WritableSignal } from '@angular/core';

@Component({
  ...,
  template: `<p (click)="upvote()">{{ playground().rating }}</p>`
})
export class PlaygroundComponent {
  playground: WritableSignal<Playground> = signal(...);

  upvote(): void {
    // value becomes {name: 'Byggepladsen', rating: 2}
    this.playground.set({name: 'Byggepladsen', rating: 2});

    // value becomes {name: 'Byggepladsen', rating: 3}
    this.playground.update(v => ({...v, rating: v.rating + 1}));
  }
}

Some signals can be modified directly

The type is WritableSignal<...>

Create using e.g signal(...)

Set value using the .set(...) method

Or update the value using .update() method
to compute a new value from the previous one

set replaces the value, update computes it from the current one. Equality is by reference: changing the object in place (playground().rating++) notifies no one. Always return a new object, like the spread in update.
