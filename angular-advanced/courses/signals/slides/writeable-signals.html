Writable signals

import { signal, WritableSignal } from '@angular/core';

interface RatedPlayground { name: string; rating: number }

@Component({
  ...,
  template: `<p (click)="upvote()">{{ playground().rating }}</p>`
})
export class PlaygroundComponent {
  playground: WritableSignal<RatedPlayground> = signal(...);

  upvote(): void {
    // value becomes {name: 'Byggepladsen', rating: 2}
    this.playground.set({name: 'Byggepladsen', rating: 2});

    // value becomes {name: 'Byggepladsen', rating: 3}
    this.playground.update(v => ({...v, rating: v.rating + 1}));
  }
}

Some signals can be modified directly

The type is WritableSignal<...>

Create using e.g signal(...)

Set value using the .set(...) method

Or update the value using .update() method
to compute a new value from the previous one

set replaces the value, update computes it from the current one. Equality is by reference: playground().rating++ notifies no one. Return a new object (the spread in update). A signal you create with signal() is writable. The type is WritableSignal. Two ways to change it. set replaces the value. update gives you the current value and you return the new one. The catch is equality: a signal compares by reference. playground().rating++ changes the object but the signal still holds the same object, so nobody is notified. That is why update returns a new object with the spread. Treat signal values as immutable. Here the click calls upvote(), which updates the signal, and the template re-renders the rating.
