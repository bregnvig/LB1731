Writeable signals

import { signal } from '@angular/core'; @Component({  ...,  template: `<p (click)="upvote()">{{ playground().rating }}</p>`})export class PlaygroundComponent {  playground: WriteableSignal<Playground> = ...;   upvote(): void {    // value becomes {name: 'Byggepladsen', rating: 2}    playground.set({name: 'Byggepladsen', rating: 2});     // value becomes {name: 'Byggepladsen', rating: 3}	    playground.update(v => ({...v, rating: v.rating + 1}));  }                    }

Some signals can be modified directly

The type is WriteableSignal<...>

Create using e.g signal(...)

Set value using the .set(...) method

Or update the value using .update() method
to compute a new value from the previous one
