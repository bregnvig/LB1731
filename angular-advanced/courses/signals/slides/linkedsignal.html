linkedSignal

Writable, like signal

Resets when its source changes, like computed

Stable since v20

Example:

The first playground is selected. The user can select another. When the list is replaced, the selection goes back to the first.

playgrounds = signal<Playground[]>([]);

selected = linkedSignal(() => this.playgrounds()[0]);

select(playground: Playground) {
  this.selected.set(playground);
}
Demo: /signals/linked, the left column. Select random, then New playgrounds: the selection resets. Also /signals/model: the pagination writes page, and switching city resets it to the first page.
