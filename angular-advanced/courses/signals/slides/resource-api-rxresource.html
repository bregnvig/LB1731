Resource Api - rxResource

Good for integrating existing RxJS observables!

Like resource, but the loader returns an Observable

 

Every value the Observable emits becomes value()

 

Automatically re-runs whenever params change.

userId = input.required<string>();

user = rxResource({
  params: () => ({ id: this.userId() }),
  stream: ({ params }) => this.userData.load(params.id)
});
params reads signals like computed. userId changes: old stream unsubscribed, stream runs again. State management exercise 3 uses rxResource.
