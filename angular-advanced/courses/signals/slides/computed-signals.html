Computed signals

import { computed, Signal } from '@angular/core';

@Component({
  ...,
  template: `<p>{{ distance() }}</p>`
})
export class PlaygroundComponent {
  location: Signal<Coordinate> = ...;
  playground: Signal<Playground> = ...;

  // distance is computed and memoized
  distance = computed(() => {
    return calcDist(
      this.playground(), 
      this.location()
    );
  });                 
}

Derive value from other Signals

Use the computed() function, specifying a derivation function


Computed Signals are lazily evaluated and memoized, meaning the value is calculated only when needed, and shared between all consumers

Show demo/src/app/signals/inputs/inputs.component.ts (/signals/inputs): distance = computed(...), used in the template. Lazy: nothing runs until read. Memoized: ten reads, one run, until a dependency changes.
