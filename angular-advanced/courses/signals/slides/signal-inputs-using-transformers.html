Signal inputs - using transformers

Transform the input value into a desired type

 

Built-ins like booleanAttribute & numberAttribute

@Component({...})
export class PlaygroundsComponent {
  
  showDistance = input<boolean, boolean | string>(false, { transform: booleanAttribute })
  // Optional input with a default value
  location = input<Coordinate | null>(null); 
  // Required input without an initial value
  playgrounds = input.required<Playground[], Playground | Playground[]>({
    transform: value => Array.isArray(value) ? value : [value]
  });
}
<app-playgrounds [playgrounds]="aSinglePlayground" showDistance />
booleanAttribute: showDistance is false by default; writing just showDistance on the element makes it true. playgrounds accepts one or many, the component always gets an array. Inputs can transform what the parent passes in. Angular ships booleanAttribute and numberAttribute. With booleanAttribute you can write showDistance on the element with no value, like a HTML attribute, and the component gets true. The two type parameters are what the component keeps and what the parent may pass. playgrounds accepts one playground or many. The transform wraps a single one in an array, so the component always works with an array.
