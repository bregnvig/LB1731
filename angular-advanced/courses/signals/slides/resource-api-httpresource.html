Resource Api - httpResource

Use for REST APIs and typical HTTP requests

Initiates the request eagerly. The URL is a function: it fetches again when the signals it reads change.

 

Uses Angular’s HttpClient under the hood, with automatic loading, error, and reload handling.

 

Think: request → response → maybe resourceRef

const todos = httpResource<Todo[]>(() => '/api/todos');

// Fetches again when userId changes
const user = httpResource<User>(() => `/api/users/${this.userId()}`);

// The response as text, Blob or ArrayBuffer
const readme = httpResource.text(() => '/README.md');
const logo = httpResource.blob(() => '/logo.png');

todos.value();   // Todo[] | undefined
todos.reload();  // fetch again
URL function returns undefined: waits (idle), e.g. no user selected. Built on HttpClient, so interceptors run.
