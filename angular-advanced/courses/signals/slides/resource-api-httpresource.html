Resource Api - httpResource

Use for REST APIs and typical HTTP requests

Initiates the request eagerly

 

Uses Angular’s HttpClient under the hood, with automatic loading, error, and reload handling.

 

Think: request → response → maybe resourceRef

const todos = httpResource('/api/todos'); // Response valuetodos.value(); // HttpResourceRef with string in value()todos.text(() => ({ … })); // HttpResourceRef with Blob object in value()todos.blob(() => ({ … }));  // HttpResourceRef with ArrayBuffer in value()todos.arrayBuffer(() => ({ … }));  // Fetch the resource againtodos.reload()
