Effects

import { Signal, effect } from '@angular/core';

@Component({...})
export class PlaygroundComponent {
  playgrounds: Signal<Playground[]> = ...;

  constructor() {
    effect(() => {
      localStorage.setItem(
        'playgrounds',
        JSON.stringify(this.playgrounds())
      );
    });
  }
}

Run operations whenever dependent signals change

Stable since v20

You can create an effect using the effect() function

Effects always run at least once.

Create it in an injection context (constructor or field). It's destroyed with its component or service, or call destroy() on the returned ref.

For side effects that leave Angular: localStorage, logging, third-party libs, the DOM. Runs during change detection; several changes close together give one run. Needs an injection context to know when to stop. Outside constructor/field init, pass { injector }. Demo: /signals/infinite-loop. Effects are for the other direction: when a signal changes, do something outside Angular's state. localStorage, logging, a third-party library, the DOM. Here we save the playgrounds whenever they change. That is exactly what you do in exercise 1. An effect always runs once, so it can find its dependencies. After that it runs again when any of them change. Several changes close together give one run. It needs an injection context: constructor or field initializer.
