Effects

import { Signal, effect } from '@angular/core';

@Component({...})
export class PlaygroundComponent {
  playgrounds: Signal<Playground[]> = ...;

  constructor() {
    effect(() => {
      localStorage.setItem(
        'playgrounds',
        JSON.stringify(this.playgrounds())
      );
    });
  }
}

Run operations whenever dependent signals change

Stable since v20

You can create an effect using the effect() function

Effects always run at least once.

Create it in an injection context (constructor or field). It's destroyed with its component or service, or call destroy() on the returned ref.

For side effects that leave Angular: localStorage, logging, a third-party library, the DOM. Timing: it runs during change detection, and several changes close together give one run. Injection context: effect needs the injector to know when to stop. Outside a constructor or field, pass { injector }. Show the infinite-loop demo (/signals/infinite-loop): the effect writes playgrounds, which it also reads, so it runs again (it stops at 200).
