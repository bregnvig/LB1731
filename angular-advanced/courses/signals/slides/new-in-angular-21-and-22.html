New in Angular 21 and 22

  • v21: new apps are zoneless
  • v22: OnPush is the default
  • v22: resources are stable
  • v22: linkedSignal can guard writes
  • v22: debounced() (experimental)
  • v22: Signal Forms are stable
// Writes go through set; rawSet does the real write
quantity = linkedSignal({
  source: this.cart,
  computation: () => 1,
  set: (value, rawSet) => rawSet(Math.max(1, value)),
});

// A resource that settles 300 ms after the last change
query = signal('');
debouncedQuery = debounced(this.query, 300);
debouncedQuery.value();
debounced returns a resource, not a signal: read .value(); loading while the user types. Pair with httpResource for search. Experimental. Signal Forms (@angular/forms/signals): own topic, just point at them.
