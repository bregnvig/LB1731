View child

  • Similar to a template reference variable Remember #myComponent
  • Injected into the component by the framework

  • Uses the viewChild (v17.2) signal query or the @ViewChild decorator 

  • Injected by type or by template reference variable name

  • If more components are being selected by the viewChild/@ViewChild the first child that meets the criteria will be injected

Ask if everybody remembers what a template reference variable is. viewChild was introduced in 17.2 and has been stable since v19
