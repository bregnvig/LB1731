Go to labs/components/exercise-1 and run npm install. When complete, start the application using npm start

 

  • Create a sidebar-list-item component in the sidebar directory using the Angular CLI.
  • Move the <button> element from the sidebar into the new component. Remember to leave the @for in the sidebar.
  • Add the following input properties to the new component: playground, selected: boolean & location: Coordinate | null.
  • In sidebar-list-item use selected for [class.active], remove the click event and then the rest should be fairly self explanatory.
  • Back in the sidebar use the the sidebar-list-item, instead of the <button> element.
    Remember to use the input properties.
