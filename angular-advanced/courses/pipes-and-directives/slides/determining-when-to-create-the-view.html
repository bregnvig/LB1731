determining when to create the view

@Directive({  selector: '[loopIsInRole]'})export class IsInRoleDirective {   constructor(    private template: TemplateRef<any>,    private viewContainer: ViewContainerRef,    private authService: AuthService  ) { }   @Input()  set loopIsInRole(role: Role) {    const isInRole = this.authService.isInRole(role);    if (isInRole && !this.viewContainer.length) {      this.viewContainer.createEmbeddedView(this.template);    } else if (!isInRole && this.viewContainer.length) {      this.viewContainer.clear();    }  }}
We use a provided value to determine whether we should create the view. Mention that the set methods name is the same as the selector
