Exercise 3 - Custom Attribute directive

  • Not happy with the result of the previous exercise? Go to the the labs/pipes-directives/exercise-3 directory and run npm i. When complete, start the application using npm start
  • Create using the CLI command npx ng g d directive/selectAllText --skip-tests
  • The purpose of the SelectAllTextDirective is to select all text of an input element when focused.
  • Use select method on the nativeElement of the host to select text.
  • The directive is to be applied on at least the name input in EditPlaygroundControlComponent
