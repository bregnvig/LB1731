pipe requirements

  1. An exported class
  2. A pipe decorator
  3. Implement the PipeTransform interface
  4. Use standalone: false, and add class to module declaration  >= v19
  5. Use standalone: true, or add class to module declaration  <v19
  6. Any clean up can be performed in the ngOnDestroy method - there is no ngOnInit
