The syntax

The asterisk * syntax on a structural directive, such as *ngIf, is shorthand that Angular interprets into a longer form

Angular transforms the asterisk in front of a structural directive into an <ng-template> that surrounds the host element and its descendants.

 Other modifiers on the host element remain in place as the element moves inside the <ng-template>.

<ng-template [loopIsInRole]="'anonymous'">  <span [class.some-class]="isAnonymous">I'm anonymous</span></ng-template>
Remains when moved inside - [class.some-class] in this instance
