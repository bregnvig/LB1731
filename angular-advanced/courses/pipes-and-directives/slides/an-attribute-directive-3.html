An Attribute directive

@Directive({ selector: '[loopExpand]' })
export class ExpandDirective {

  loopExpand = input<boolean, boolean | string>(false, {transform: booleanAttribute});

}

An Input Decorator

<input  loopExpand/>          <!-- Will expand -->
<input [loopExpand]="true"/>  <!-- Will expand -->
<input [loopExpand]="false"/> <!-- Will not expand -->
So using the exact same name as An input decorator must be prefixed with the directive name Databinding is just as the one used between components
