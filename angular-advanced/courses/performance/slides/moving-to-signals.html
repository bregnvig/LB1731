Only if asked. Good: no markForCheck, no cleanup (toSignal and effect end with their injection context), computed lazy + memoised. Moving to signals is mostly good news. A signal read in a template tells Angular to update that view, so no markForCheck. toSignal unsubscribes when its injection context is destroyed, and an effect is destroyed with it, so there's no cleanup code. And computed is lazy and memoised: if nobody reads it, the function never runs, and if the inputs did not change, it does not run again.
