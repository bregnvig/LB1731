Only if asked. effect and toSignal are eager. Rule: derive with computed, side effects only in effect. Now the bad news, which is a performance point. effect and toSignal are eager. An effect runs during change detection whether or not anyone needs what it does. toSignal subscribes immediately, even if you never read the signal, so an HTTP request you forgot about still goes out. So the guidance: derive values with computed, because it only costs when read, and keep effect for real side effects.
