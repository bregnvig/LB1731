Bad: effect and toSignal are eager. effect runs during CD at least once; toSignal subscribes immediately. Rule: derive with computed, side effects only in effect. Now the bad news, which is a performance point. effect and toSignal are eager. An effect runs during change detection whether or not anyone needs what it does. toSignal subscribes immediately, even if you never read the signal, so an HTTP request you forgot about still goes out. So the guidance: derive values with computed, because it only costs when read, and keep effect for real side effects. Do not use an effect to copy state, we covered that in the signals module.
