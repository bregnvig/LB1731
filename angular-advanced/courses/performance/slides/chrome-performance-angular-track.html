Console: ng.enableProfiling(), then record in the Performance panel. Angular track: components, CD cycles, what was checked or skipped. Blue = your TS, purple = template, green = entry points. Dev mode only. Use this one for long tasks and timing; DevTools for who was checked. Click: the colours. "Dev mode only" is in the notes now. The second tool lives in Chrome's own Performance panel. Angular can write its work into the performance timeline, but you switch it on yourself: type ng.enableProfiling() in the console of a dev build. Then record as usual. Next to the usual tracks there is an Angular track. It shows your components, the change detection cycles, and the colours tell you where time went: blue for your TypeScript, purple for template code, green for the entry points. Which one to use? The Angular DevTools Profiler is simplest for counting cycles and seeing which components were checked. The Performance panel is better when you want to see timing next to everything else the browser does: layout, paint, long tasks. We use both.
