Zoneless: what schedules change detection?

Both schedule a check:

  • A signal read in a template changes
  • A template or host listener fires
  • markForCheck(), the async pipe

Only zone.js:

  • setTimeout, setInterval
  • A promise or request finishes

If the screen should change, change a signal.
