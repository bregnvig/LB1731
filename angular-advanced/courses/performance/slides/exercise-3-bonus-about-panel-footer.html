async toggleAbout() {
  if (this.about()) {
    this.about.set(null);
  } else {
    const { AboutComponent } =
      await import('../about/about.component');
    this.about.set(AboutComponent);
  }

Template: <ng-container *ngComponentOutlet="about()"/>, NgComponentOutlet in imports, about = signal<Type<unknown> | null>(null). await import() gives you the file, and from it the component class. The bundler puts that file in its own chunk, so nothing is downloaded until that line runs. NgComponentOutlet takes a component type and renders it, and with null it renders nothing. The signal holds the type, so it works zoneless too.
