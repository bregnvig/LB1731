Exercise 3 - Bonus: Om appen

  1. In src/app/footer/footer.component.ts: a signal holds the type, await import(...) on click, *ngComponentOutlet shows it (add NgComponentOutlet to imports)
about = signal<Type<unknown> | null>(null);

async toggleAbout() {
  if (this.about()) {
    this.about.set(null);
  } else {
    const { AboutComponent } = await import('../about/about.component');
    this.about.set(AboutComponent);
  }
}
Template: <ng-container *ngComponentOutlet="about()"/>. Alternative: ViewContainerRef.createComponent. Step two: await import() gives you the file, and from it the component class. The bundler puts that file in its own chunk, so nothing is downloaded until that line runs. Step three: render it. NgComponentOutlet takes a component type and renders it, and with null it renders nothing. The signal holds the type, so it works zoneless too. The other way is createComponent on a ViewContainerRef; NgComponentOutlet is shorter.
