Where did Zone.js live? In polyfills

// angular.json, build options
"polyfills": [
  "zone.js",
  "@angular/localize/init"
],

Remove the "zone.js" line. That is all the build needs.

ng build output, exercise 2, before and after

  • polyfills: 35.09 kB (11.52 kB transferred) → 494 bytes
  • initial total: 394.85 kB → 383.17 kB transferred
  • main: 357.77 kB → 357.12 kB transferred. Not where the saving is

The saving is Zone.js itself, gone from the polyfills file.

Don't say "main got smaller". Say polyfills shrank: 35.09 kB -> 494 B (transfer 11.52 kB -> 494 B). Initial total transfer 394.85 -> 383.17 kB. main 357.77 -> 357.12 kB transfer: basically the same. The students will measure it themselves in exercise 2. One more thing zoneless gives you: a smaller download. Zone.js is not part of your app's main bundle, it lives in the polyfills file, listed in angular.json. In the build output you will see the polyfills file drop from 35 kilobytes, 11.5 over the wire, to 494 bytes. Initial total goes from about 395 to 383 kilobytes transferred. The main file is practically unchanged, so do not expect it to shrink: the saving is that Zone.js is gone. This is a small win for startup, and the bigger win is runtime: no patched APIs and no cycles after every timer. You will measure both.
