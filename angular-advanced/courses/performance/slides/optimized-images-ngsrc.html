Images: ngSrc

  • ngSrc instead of src (NgOptimizedImage)
  • priority on the LCP image. Without it, dev mode logs NG02955
  • width + height, or fill
<img ngSrc="/assets/performance/hero.webp"
  width="2400" height="1200" priority>

<div class="fill-box">
  <img ngSrc="/assets/performance/sandbox.webp"
    fill>
</div>
Demo: /performance/images. Console open, click Reload without priority: error NG02955 for hero.webp. Click Reload with priority: console clean. Only if asked: the playground app has no big images, so there's no exercise. Replace src with ngSrc and import NgOptimizedImage. You get lazy loading by default and dev mode warnings for the usual mistakes. Put priority on the LCP image, the biggest thing above the fold. Console open, Reload without priority: NG02955. Reload with priority: clean. Width and height are required, so the browser reserves the space. If you don't know the size, use fill with a positioned parent.
