Exercise 3 - Watch the chunks load

  1. Stop the server and restart it with: npm run start:no-hmr
  2. DevTools, Network, JS, filter /main\.js|component/, reload
  3. Click a playground, then Details

Running npm start without the ;no-hmr loads every @defer chunk up front. 

npm run start:no-hmr. Network, JS, filter /main\.js|component/ (slashes included: a regex), reload. leaflet.component right after main; playground-detail.component only after Details. Helping a group: every chunk at once means they still run plain npm start, whose hot module replacement loads defer chunks eagerly. An empty list means the filter is missing its slashes.
