Exercise 3 - Watch the chunks load

  1. Stop the server, run npm run start:no-hmr
  2. DevTools, Network, JS, filter /main\.js|component/, reload
  3. Click a playground, then Detaljer

Trap: plain npm start (hot module replacement) loads every @defer chunk up front.

npm run start:no-hmr. Network, JS, filter box /main\.js|component/ (slashes included: a regex), reload. leaflet.component right after main (initiator main.js). Detaljer: playground-detail.component (initiator app.routes.ts). The build table told us the chunks exist. Now we watch them load. Stop the dev server and start it with npm run start:no-hmr. Hot module replacement loads every defer chunk up front, so with plain npm start the Network tab shows nothing interesting and you'd think defer is broken. Network tab, JS. The dev server serves a lot of small vendor files, so type /main\.js|component/ in the filter box, slashes included: that's a regular expression. Reload. Right after main you see leaflet.component, started by main.js: on idle fires fast on an idle laptop. Now click a playground and then Detaljer. Only then does playground-detail.component show up, and its initiator is app.routes.ts. That's the lazy route. Ask the room: on a phone on a slow network, which of those would you rather have the user wait for?
