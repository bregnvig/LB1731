Exercise 3 - Watch the chunks load

  1. Start the app with npm start -- --no-hmr
  2. DevTools, Network tab, filter JS, type /main\.js|component/ in the filter box, reload

Trap: with plain npm start, hot module replacement loads every @defer chunk up front. You'd see nothing.

npm start -- --no-hmr. Network, filter JS, filter box /main\.js|component/, reload. Plain npm start loads defer chunks up front: the most common "defer doesn't work" question. The build table told us the chunks exist. Now we watch them load. Stop the dev server and start it with npm start -- --no-hmr. Hot module replacement loads every defer chunk up front, so with plain npm start the Network tab shows nothing interesting and you'd think defer is broken. Network tab, filter on JS. The dev server serves a lot of small vendor files, so type /main\.js|component/ in the filter box, slashes included: that's a regular expression. Reload. Next slide: what you see.
