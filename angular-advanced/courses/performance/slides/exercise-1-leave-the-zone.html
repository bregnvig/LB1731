Inject NgZone, wrap mapContructor(...) only. Reload. Measure after: same 5 s -> mousemove bars gone, one per second left (footer). Compare the count. Leaflet registers map listeners at creation, so only creation needs to be outside. Zoom buttons / marker hover are added later and still run in the zone. Now the fix. Open leaflet.component.ts. Inject NgZone, and in ngAfterViewInit wrap just the call that creates the map in runOutsideAngular. It is one expression, so it becomes an arrow function that returns the map, and you need an extra closing parenthesis after the options object. Why is wrapping the creation enough? Leaflet registers its mousemove, drag and zoom listeners when the map is created. Because that happens outside the zone, they are never patched, so no cycles. Measure after: reload, record the same five seconds. The wall of bars is gone. What remains is one bar per second. That is the footer's timer, we leave it for the bonus and for exercise 2. Small caveat: the zoom buttons and the marker hovers are added after creation, so they are still inside the zone. Clicking them still runs a cycle. That is fine, it is a click, not a stream.
