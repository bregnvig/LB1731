Reading the build output

  • npm run build: the chunk table
  • Initial: before the app starts
  • Lazy: fetched later
  • Raw: the file. Transfer: compressed

The line to watch: Initial total

Only if the room has never read the build table. Exercise 3 getting started says the same in one line. npm run build prints a table. The first table is the initial chunk files: everything the browser downloads and runs before the app starts. Initial total is the number we push down. Once something is lazy, a second table shows up: lazy chunk files. Raw size is the file on disk. Estimated transfer size is what goes over the wire after compression. Slow connections feel the second, parsing and running costs the first.
