content-visibility: auto

Skip layout and paint of off-screen rows

The node count stays the same: only render work goes down

contain-intrinsic-size reserves a height so the scrollbar is stable

styles: `
  :host {
    display: block;
    content-visibility: auto;
    contain-intrinsic-size: auto 66px;
  }
`,
Pure CSS: the browser skips layout and paint of rows that are off screen. Does NOT reduce the node count. It reduces rendering work. contain-intrinsic-size gives the skipped rows a height so the scrollbar doesn't jump. auto remembers the real one. Bonus in exercise 4. If you cannot remove nodes, you can make them cheaper. content-visibility auto tells the browser: do not do layout or paint for this element while it is off screen. It is pure CSS, no JavaScript. The element's size is unknown while it is skipped, so the scrollbar would jump. contain-intrinsic-size gives it a placeholder size. The auto keyword means: once you have rendered it, remember the real size. Be clear on what it does: the node count stays at about 1,020. What goes down is the time spent in layout and rendering, which you see in the Performance panel. That is a different problem from memory. That is the bonus in this exercise: put it on the list item host.
