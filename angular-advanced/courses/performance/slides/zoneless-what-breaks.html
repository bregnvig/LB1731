Zoneless: what breaks

Field set in a timer → signal

fakeAsync → keep zone.js/testing

NgZone.onStable → afterNextRender

Only if asked: what to look for in your own code before taking zone.js out. Only the first one is in our app (the footer). Click. The one you'll hit today: a plain field written in setTimeout, setInterval, a promise or a subscribe. With zone.js, the cycle after the task picked it up. Zoneless, nothing schedules a cycle, so the screen stays where it was. Make it a signal. Click. Tests: fakeAsync and tick are built on zone.js. Keep zone.js/testing in the test polyfills for those specs, or move them to real timers or your test runner's fake timers. Click. Code that waits for the zone to settle, NgZone.onStable or onMicrotaskEmpty, often in third-party wrappers or old directives. Zoneless, those never emit. If what you want is "after Angular has rendered", that's afterNextRender.
