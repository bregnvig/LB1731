The trash icon collects garbage: what is left is really held.

Memory tab, Heap snapshot. Trash icon before every snapshot. Four clicks, then why the trash icon. A heap snapshot is a photo of every object in memory. You take two around the same trip and compare. Open DevTools, Memory tab, Heap snapshot. Click the trash can first: that forces a garbage collection, so what's left is really being held. Take snapshot one. Do the trip a few times, trash can again, snapshot two.
