Exercise 4 - Read the retainers

Leaflet's resize listener on window

The footer's setInterval callback

Only map.remove() takes the listener off. Nobody calls clearInterval.

Click: Leaflet. Click: the footer. The two culprits. Click. Leaflet did. A map listens for window resize, and only map.remove() takes the listener off. Nobody calls it, so the map keeps its container, and a detached node keeps its parents, so the whole old Home stays. The footer is the other half: the setInterval callback still runs every second and holds the footer.
