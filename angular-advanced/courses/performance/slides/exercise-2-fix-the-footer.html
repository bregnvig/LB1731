Exercise 2 - Fix the footer with a signal

Lab labs/performance/exercise-2, file src/app/footer/footer.component.ts

  1. seconds becomes signal(0)
  2. Write it with .set(...), read it as seconds() in the template
  3. Delete the changeDetection line and the ChangeDetectionStrategy import from the footer and from every other component: OnPush is the default

Measure after: the counter counts again. Record 10 quiet seconds: still one bar per second, but now only the footer is refreshed. Move the mouse over the map: no bars. Run npm run build: polyfills is 494 bytes.

import { Component, Input, signal } from '@angular/core';

  seconds = signal(0);

  constructor() {
    setInterval(() => this.seconds.set(Math.round((Date.now() - this.loadedAt) / 1000)), 1000);
  }

// template:
<p><small>Opdateret for {{ seconds() }} sekunder siden</small></p>
signal(0), .set(), seconds() in template, remove changeDetection + its import, in every component. @Input()s stay as they are (inputs set by the parent mark the view). Measure after: bars only when the signal changes (every second, footer only), none from the mouse; polyfills 494 B. No markForCheck needed. The fix is small. Make seconds a signal, set it in the interval, and call it in the template. Then delete the changeDetection line, so the footer is OnPush like everything else, and delete the import that is no longer used. Do the same in the other six components: the app, home, sidebar, list item, detail page and the Leaflet wrapper. Then no component is checked by default any more. Why does it work? The template reads the signal. When the interval sets a new value, Angular marks exactly that view for refresh and schedules a cycle. No markForCheck, no zone, no Eager. Measure after. The counter counts. In the profiler you still have one bar per second, because the number really does change every second, but now the cycle refreshes only the footer. Move the mouse over the map and nothing happens. Run the build again and compare the polyfills line with your before number. Compare all three states: step one, mouse bars everywhere.
