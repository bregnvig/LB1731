Exercise 1 - Getting started

Install Angular DevTools in Chrome (Chrome Web Store) before anything else.

Change directory to labs/performance/exercise-1, then run

npm install
npm start

Open http://localhost:4200. Allow location access when the browser asks: the playground list waits for it. The backend is slow on purpose (3 seconds).

The rule: measure, change, measure again.

The app is the one from the signals course, with seeded problems. This lab: the map makes Angular work on every mouse move.

You will record with the Angular DevTools Profiler (see the tools slides), or with ng.enableProfiling() and the Chrome Performance panel.

Do not skip the recording before you change anything.
