Exercise 4 - Fix the leaks

  1. Map: after createMap, remove on destroy
  2. Footer: clear the setInterval on destroy
  3. Import DestroyRef from @angular/core in both files
// src/app/leaflet/leaflet.component.ts
private destroyRef = inject(DestroyRef);
// in ngAfterViewInit, after createMap(...)
this.destroyRef.onDestroy(
  () => _map.remove());
// src/app/footer/footer.component.ts
const id = setInterval(/* … */);
inject(DestroyRef).onDestroy(
  () => clearInterval(id));

You should see: the map and the counter work as before.

Footer: const id = setInterval(...); inject(DestroyRef).onDestroy(() => clearInterval(id)). Leaflet: field destroyRef, onDestroy(() => _map.remove()) right after the map is created. Helping a group: register the callbacks right where the interval and the map are created, not in ngOnDestroy. NG0911 in the console means they registered after the component was destroyed, for example after an await.
