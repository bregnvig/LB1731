Exercise 3 - In your app

  1. npm run build: write down Initial total
  2. npm run build -- --stats-json, open it in the analyzer: the three biggest things in main?
  3. Registered whole? Make it one by one. Rarely visited route? Load it lazily
  4. Heavy and below the fold? @defer it, then build again
Monday homework for lab 3: Initial total, analyzer, biggest three, then the cheapest change first. Exercise 3 in your own app. Build it and write down Initial total. Then the stats flag and the analyzer, and name the three biggest things in main. Then work down the list: something registered whole, like icons or locales, becomes one-by-one. Routes almost nobody visits get loadComponent. Heavy components below the fold or behind a click get @defer. Build after each change.
