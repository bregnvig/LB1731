Still on zone.js? This is your cheapest fix.

Click through the highlights: the injected zone, then the wrapped createMap call. Click: the punchline. Here's the tool. NgZone.runOutsideAngular takes a function and runs it outside the zone. Anything it starts, event listeners and timers, isn't patched, so zone.js doesn't trigger change detection after them. Be precise: only zone.js stops. A signal you set in there, or a markForCheck, still schedules a check. The catch: a plain field you change in there does change, but the screen keeps the old value. Ask the room: when will it show the new number? At the next cycle, whatever starts it. Fine for a map that draws its own DOM. If a template depends on something in there, set a signal. The code is exercise 1. The map is created inside runOutsideAngular, and the arrow function returns it, so const _map still works. Leaflet adds its listeners when the map is created, so wrapping creation is enough. Click.
