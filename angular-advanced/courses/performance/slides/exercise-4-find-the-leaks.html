If you want a clean start, labs/performance/exercise-4, npm install, npm start. Open DevTools, Memory, Heap snapshot. On the home page, take snapshot one. A snapshot always collects garbage before it's taken, so what's in it is really being held. Now five rounds. Select a playground in the list, click Detaljer in the footer, and click Tilbage til kortet on the detail page. Five times, and count them: the numbers only make sense if you know how many rounds you did. Then take snapshot two. If you want a quicker look in your own app later: the same panel has a profile type called Detached elements, which lists detached DOM trees straight away.
