Lazy routes

  • loadComponent for one standalone component
  • loadChildren for a route tree
  • The bundler splits at the import()
{
  path: 'admin',
  loadChildren: () =>
    import('./admin/admin.routes')
      .then(m => m.ADMIN_ROUTES),
},

The catch: any other use of the class keeps it in main

Only if asked: loadChildren for a route tree. The lab uses loadComponent (exercise 3 slide). loadChildren is for a group of routes, say everything under /admin. The imported file exports a Routes array, and if it's the default export you don't even need the then. The catch: it only works if nothing imports the component the normal way. The build won't warn you, so you check the lazy table.
