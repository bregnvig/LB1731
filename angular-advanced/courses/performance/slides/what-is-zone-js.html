What is Zone.js?

Patches events, timers, promises, XHR

Runs change detection after every task

Can't tell if state changed 🤔

Adds JavaScript to your bundle 🙄

Four clicks, one line each. Only if someone asks what zone.js is. Zone.js wraps the browser APIs that run your code later: addEventListener, setTimeout, setInterval, promises, XHR. Angular listens to the zone, and when a task finishes it runs change detection over the whole app. That is why Angular used to just work. You assign a field in a callback, and the screen updates. Nobody told Angular, the zone guessed. The price: it cannot tell whether anything changed, so every mouse move and every timer tick pays for a full cycle. And it is code in your bundle: we see its size in the build output in exercise 2.
