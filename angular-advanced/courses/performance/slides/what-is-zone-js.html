What is Zone.js?

  • It "monkey patches" the browser's async APIs: events, timers, promises, XHR
  • After every task it runs change detection for the whole app, so Angular updates seamlessly 😁
  • It knows a task finished, not that state changed., so most cycles change nothing 🤔
  • It adds JavaScript to your bundle 🙄
Monkey patch: change runtime behaviour without touching the source. Patches setTimeout, setInterval, addEventListener, promises. Runs CD after each callback. Knows "a task ended", not "state changed". Costs bytes (polyfills, see exercise 2). Zone.js wraps the browser APIs that run your code later: addEventListener, setTimeout, setInterval, promises, XHR. Angular listens to the zone, and when a task finishes it runs change detection over the whole app. That is why Angular used to just work. You assign a field in a callback, and the screen updates. Nobody told Angular, the zone guessed. The price: it cannot tell whether anything changed, so every mouse move and every timer tick pays for a full cycle. And it is code in your bundle: we will see its size in the build output in exercise 2. Keep this in mind for the first lab: the map fires events constantly, and every one of them starts a cycle.
