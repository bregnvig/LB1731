OnPush is the default (v22)

Every component is OnPush unless it opts out

The old default is now called Eager

An OnPush component is checked when

  • an input changes
  • an event fires in its template
  • a signal its template reads changes

Cut from the slide: ng update adds Eager to every component, so every component in this app has it. Since Angular 22 every component is OnPush unless it says otherwise. The old default is now called Eager, and Default is a deprecated alias for it. Eager means: check me every time change detection walks past. That's how the footer's plain field works under Zone.js: the zone runs a cycle every second, the footer is checked, the new number shows. ng update adds Eager to every component so nothing changes behaviour, and our app looks exactly like that.
