OnPush is the default (v22)

  • Every component is OnPush unless it opts out
  • The opt-out: Eager, the old Default
  • Checked on a new input, a template event, a signal it reads. A mutated input object is no new input

Recap from signals. Eager = the old Default: checked whenever the walk reaches it. ng update to 22 adds Eager to every component. Mutated input object: same reference, so OnPush sees no change. That's an OnPush rule, with or without zone.js. Since Angular 22 every component is OnPush unless it says otherwise. The old default is now called Eager, and Default is a deprecated alias for it. Eager means: check me every time change detection walks past. That's how the footer's plain field works under zone.js: the zone runs a cycle every second, the footer is checked, the new number shows. ng update adds Eager to every component so nothing changes behaviour, and our app looks exactly like that. An OnPush component is checked when an input gets a new value, an event fires in its template, or a signal its template reads changes. The catch with inputs: a new value means a new reference. Push to an array that a child gets as an input, and the reference is the same, so OnPush sees nothing and the child stays stale. Pass a new array or object, or make it a signal. That's OnPush, it has nothing to do with zone.js. In exercise 2 you make the counter a signal, then the Eager lines can go.
