constructor() {
  inject(NgZone).runOutsideAngular(() =>
    setInterval(() => this.seconds = Math.round((Date.now() - this.loadedAt) / 1000), 1000));

TRY AND REVERT. Not part of the solution. Footer interval outside the zone: bars gone, counter frozen (updates only when something else runs CD, like a click on a playground). Point: zone.js was the trigger. Plain field + no zone = no update. Lead-in to exercise 2. Revert before the break. A bonus for the fast ones, and it is a try and revert experiment. Do not keep this change. The footer counts seconds with a setInterval that writes a plain field. Wrap that interval in runOutsideAngular, the same trick as for the map. Look at the profiler: the footer's bars are gone. Great? Look at the page. The counter has stopped. The field is still updating, but the screen is not, because nothing tells Angular to check the footer. It only moves if something else triggers a cycle, for example if you click a playground. That is the whole lesson: the only reason the counter ever updated was zone.js, running a cycle after each timer tick. Runs outside the zone, no cycle, no update. Now undo it, so you start the break with the working footer. After the break we remove zone.js completely and the same thing will happen to the whole app, and then we fix it the right way.
