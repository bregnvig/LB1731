Exercise 3 - Measure the build

Measure, change, measure again. Write the number down before you touch anything.

Change directory to labs/performance/exercise-3 and run:

npm install
npx ng build

Measure before: find Initial total in the output and write down raw and transfer size, and the size of main. Expect about 1.77 MB and 383 kB.

Later, to see the lazy chunks load in the browser:

npm start -- --no-hmr

Without --no-hmr the dev server loads every @defer chunk up front, and you will see nothing. Open the Network tab and reload.
