Angular DevTools: the Profiler

  1. Install Angular DevTools from the Chrome Web Store (before the lab!)
  2. Open Chrome DevTools (F12) and the Angular tab
  3. Open the Profiler tab and press Record
  4. Use the app, press Stop

What you get

  • One bar per change detection cycle
  • Click a bar to see which components were checked and how long each took

Works on the dev server only (npm start). The page must be an Angular dev build.

Count the bars: that is our before/after number in exercise 1 and 2. Our first tool. Angular DevTools is a Chrome extension, you should have installed it before class. If not, do it now, it is in the Chrome Web Store under that name. Open DevTools with F12, there is a new Angular tab. The Profiler sub-tab has a Record button. Press it, do something in the app, press Stop. Each bar is one change detection cycle. Click a bar and you see which components were checked and how long they took. The easiest number to compare before and after is simply how many bars you get for the same ten seconds of use. It only works on a development build, which is what npm start gives you.
