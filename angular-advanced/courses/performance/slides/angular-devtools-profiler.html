F12, Angular tab, Profiler, Record, use the app, Stop. One bar = one cycle. Click a bar: components refreshed + time. Not on the slide any more: install Angular DevTools from the Chrome Web Store (exercise 1 says it too). Dev builds only: npm start. Our first tool. Angular DevTools is a Chrome extension. Check that everyone has it now, it's a one-minute install and you can't do the first two labs without it. Open DevTools, there's an Angular tab, and inside it a Profiler. Press Record, do something in the app, press Stop. Every bar is one change detection cycle. Click a bar and you see which components were refreshed and how long each took. Click for the punchline. The easiest number to compare is how many bars you get for the same thing done twice, for the same five seconds, and what one bar refreshed. That's the before and after for the next two exercises. It only works on a development build, which is what npm start gives you. Ask the room: has anyone recorded their own app with this? What did one click cost?
