npx ng build of step-4, then the same build with the @defer and @placeholder around leaflet removed. Initial total 614.82 vs 760.44 kB, lazy leaflet-component 154.78 kB, main 103.27 vs 258.11 kB. This is what the defer buys in our app. Same step, built twice: once with the map in @defer on idle, once without. With the defer, Initial total is 615 kilobytes, and leaflet comes as its own 155 kilobyte chunk. main imports that chunk with a dynamic import, and the browser fetches it when it goes idle after the first render. It's a separate request in the Network tab. Without the defer, there's no chunk. Leaflet sits in main, and Initial total is 760 kilobytes, about 146 more. A little less than the chunk, because a lazy chunk carries some loading code of its own. Ask the room: why not on viewport for the map? The placeholder fills the screen, so it's in view from the first frame and the trigger fires right away. You'll build this yourselves in a moment.
