Exercise 2 - Measure before

Not happy with the result of the previous exercise? Go to the labs/performance/exercise-2 directory and run npm install, then npm start.

  1. Run npm run build. Write down the polyfills line
  2. npm start, record 10 quiet seconds. Count the bars, click one: how many components?
  3. Record one click on a playground in the list, 3 s. Count the bars
