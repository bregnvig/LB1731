Exploding head operator🤯 

function explodingHead<T>(source: Observable<T>): Observable<string> {
  return new Observable(observer => {
    observer.next('🤯');
    observer.complete();
  });
}

timer(0, 1000).pipe(
    tap(no => console.log(`For the ${no}th. time`)),
    explodingHead
  ).subscribe(value => console.log(`My head is exploding ${value}`));

So what are we subscribing to? Not the interval as we might have thought, but the explodingHead operators returned observable! (Meaning the interval observable is never subscribed to, so not really operating on an observable here)
