forkJoin

forkJoin([a$, b$])

When two or more data sources are dependent on each other, and they need to complete before target being notified

1

A

1A

Key Difference: forkJoin waits for all observables to complete before emitting a combined value, making it different from combineLatest which emits whenever any observable emits. So if we only had one event on each observable, this would be just like combineLatest. This style is often good for updating data or making multiple AJAX calls where all responses are needed before proceeding. You know you don't need to unsubscribe, as the streams are completed
