Unlike a backend usually we want to avoid starting and stopping threads all the time Reactive Programming: Paradigm for building asynchronous, event-driven systems. Core Concepts: Streams: Continuous data flow. Observables: Represent data streams. Observers: React to changes/events. Benefits: Handles real-time updates efficiently, simplifies complex asynchronous logic. In short: Shifts from "doing something" to "reacting to events or changes."
