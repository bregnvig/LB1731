counter$.pipe(
  map(x => 1 + x)

Even though this is an extremely simple example, there are lots of situations, where you need to map for one data structure to another, filter an array etc. Look at rxjs-way.component.ts for different usage of map on line: - 25: Manipulating the input to turn it lowercase - 28: Filtering playgrounds from the input stream where name is like the term provided from the input stream. (User typed a playground name to search for an playground) - 32: Sorting the playgrounds from the input stream that's based on the already filtered playgrounds. It is all about going from one kind of data to another. Could I do it in the subscribe function? Most likely. But try to do one thing in one steps. Each operator you use in the pipe should function smoothly and logically. Each function should perform a specific task. This keeps the functions coherent and well-structured, with clear input-output relationships. Try to ensure that they do not produce unexpected side effects.
