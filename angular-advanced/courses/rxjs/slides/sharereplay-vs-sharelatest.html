shareReplay vs. shareLatest

export const shareLatest = <T>() => pipe(shareReplay<T>({ 
  bufferSize: 1, 
  refCount: true 
}));

// Turn it into a multicast
const playgrounds$ = this.service.playgrounds$.pipe(
  shareLatest()
);

// Same thing using shareReplay
const playgrounds$ = this.service.playgrounds$.pipe(
  shareReplay({ 
    bufferSize: 1, 
    refCount: true 
  })
);
Instead of configuring shareReplay each time we use shareLatest() for consistent behavior.
