Create a "watch geo location" creator

this.location$ = new Observable<GeolocationPosition>(suscriber => {
  const watchId = window.navigator.geolocation.watchPosition(
    position => suscriber.next(position), 
    error => suscriber.error(error)
  );
  return () => window.navigator.geolocation.clearWatch(watchId);
});

Creates an observable using the new operator.

The callback function has a subscriber parameter.

The subscriber provide the next, error and the complete methods.

The callback function must return a tear down function.

Think long and hard about whether you need to create your own creator🤔
