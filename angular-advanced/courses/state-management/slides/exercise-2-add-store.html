Exercise 2 - Add store

Not happy with the result of the previous exercise? Go to the the labs/state-management/exercise-2 directory

Let's create a PlaygroundStore 🍾

Create a folder called state, and place the playground.store.ts in the folder.

Using what we just learned, add the following to the store

  • playgrounds
  • update
  • delete

Start by moving the relevant code from the component into the store. Afterwards inject the store into the component and start using the store instead. Create separate error properties for the read, update and delete in the store.

When done, make sure  PlaygroundService is no longer injected into the app component

Notice how the client (app) became much cleaner 🥳
