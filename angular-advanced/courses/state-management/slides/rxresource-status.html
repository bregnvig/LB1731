Idle undefined The resource has no valid request and the loader has not run. Error undefined The loader has encountered an error. Loading undefined The loader is running as a result of the request value changing. Reloading Previous value The loader is running as a result calling of the resource's reload method. Resolved Resolved value The loader has completed. Local Locally set value The resource's value has been set locally via .set() or .update()
