You Can Speed it up

the testBed is not always needed

->

~ -40ms

describe('AuthService', () => {  let service: AuthService;  beforeEach(() => {    service = TestBed.inject(AuthService);  });});
describe('AuthService', () => {  let service: AuthService;  beforeEach(() => {    service = new AuthService();  });});
TestBed takes some time to start up. Removing the TestBed from AUTHSERVICE STATE TEST improved the speed from 240ms to 200ms on average. Why would you ever need the testbed in a service? - Maybe if you have many dependencies injected in constructor. (TestBed injector handles param order). - In this case you might have too many dependencies in your service.
