Running the specs

npm test starts watch mode. Save a file and the affected specs run again.

The NG0914 warning "zone.js is still loaded" on every run is expected: the app keeps zone.js, while src/test-providers.ts makes the tests zoneless.

npm test = watch mode. NG0914 zone.js warning on every run: expected. npm test starts Vitest in watch mode. Leave it running in a terminal and every save reruns the affected specs. Behind the scenes src/test-providers.ts makes the tests zoneless. You do not need to touch it. That is also why every run prints the NG0914 warning that zone.js is still loaded: the app keeps zone.js, the tests do not use it. Ignore it.
