Test structure

it

it('should be logged in after login', () => {
  // Arrange
  const service = TestBed.inject(AuthService);
  const [email, password] = ['dummy@email.com', '*****'];
  // Act
  service.login(email, password);
  // Assert
  expect(service.isLoggedIn).toEqual(true);
});
Try to have as little shared state between each it Each it should test a Unit. Eg. a returnvalue/exception thrown, state change or 3rd party API call A unit test should only test one concern. We don't want concerns in one test. It can ruin the readability.
