Three outcomes in the playground app

Returns

filterPlaygrounds

export function filterPlaygrounds(playgrounds: Playground[], query: string): Playground[] {
  const q = query.trim().toLowerCase();
  return playgrounds.filter(playground => playground.name.toLowerCase().includes(q));
}

The test looks at: the return value, the state read through the public API, the request that left for HttpClient.

filterPlaygrounds: input in, list out. FavoritesService: toggle, then read favoriteIds(). PlaygroundService: the GET for assets/copenhagen.json. Same idea, three shapes. filterPlaygrounds is a pure function: you pass a list and a query and look at what comes back. That is exercise 1. FavoritesService keeps a list of ids. You call toggle and then read favoriteIds. The state is the outcome. That is exercise 2. PlaygroundService fetches the Copenhagen playgrounds with HttpClient. We do not want a real request in a test, so the test replaces the third party and checks that the right GET was sent. That is exercise 3.
