A suite within a suite

Improve the readability of your test suites

describe('AuthService', () => {  describe('Initially', () => {    //...  });  describe('When logged in', () => {    //...  });  describe('When not logged in', () => {    //...  });});
It is not illegal to have multiple describes in a describe. This can vastly improve the readability of your code. Instead of writing in the test "when not logged in should throw error" + "when not logged in should..." Each describe is self contained so they won't touch each others module setup.
