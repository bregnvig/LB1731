Test structure

Before/AFTER - Each/ALL

describe('AuthService',  () => {  let service: AuthService;    beforeEach(() => {    TestBed.configureTestingModule({});    service = TestBed.inject(AuthService);  });    afterAll(() => {    cleanUpDatabase(globalDb);  });});
Best practices: Aftereach should NEVER clean up state. It is not guaranteed to run, especially if you have multiple. State reset (if needed at all) should ALWAYS go in the beforeEach You should ask yourself: is resetting the state even necessary? If so: jest.resetModules() Resets the module registry - the cache of all required modules. This is useful to isolate modules where local state might conflict between tests.
