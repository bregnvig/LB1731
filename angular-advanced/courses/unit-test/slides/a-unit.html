A unit of work. Not a function, not a class or something like that

A UNIT

A unit is invoked by a public API. (file system/database)

One of three outcomes:

  • Returns a value/exception
  • Changes a state
  • Calls a 3rd party API (3rd party library or some Web API)

Doesn't touch the file system/database

Roy Osherove 

The Art Of Unit Testing

Public API is whatever is publicly accessible from your application. Third party API could be an external service or third party module.
