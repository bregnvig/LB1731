Karma

MOVING PIECES

A test runner built by the angularJS team to make TDD seamless in Angular development.

Deprecated as of April 2023

Karma runs tests in the browser

Karma can be extended through plugins

Deprecation in April 2023 Karma is not a framework nor a platform. It is a test runner built by the angularJS team to make TDD seamless in Angular development. Karma runs in its own browser environment which means Karma opens up the browser in order to run the tests. Karma runs the specified test files in the karma.conf.ts in order to run the relevant testings.
