Providing a control

  • The control must be provided to the framework to be usable.
@Component({  selector: 'loop-address-control',  templateUrl: './address-control.component.html',  styleUrls: ['./address-control.component.scss'],  providers: [    {      provide: NG_VALUE_ACCESSOR,      useExisting: forwardRef(() => AddressControlComponent),      multi: true    }  ],})

Now you are done kinda

I forgotten to register a control a hundred times, and the error message used to be really hard to decipher. Now it is quite good: No value accessor for form control with name: 'homeAddress' Show what happens if you forget to provide it
