The custom controls validity

  • Implement the Validator interface
  • The validate method will be called every time your custom control is about to propagates a change
  • Register the validator:
@Component({  selector: 'loop-address-control',  templateUrl: './address-control.component.html',  styleUrls: ['./address-control.component.scss'],  providers: [    {      provide: NG_VALIDATORS,      useExisting: forwardRef(() => AddressControlComponent),      multi: true    }  ],})
