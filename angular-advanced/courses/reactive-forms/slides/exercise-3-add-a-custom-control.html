Exercise 3 - Add a custom control

Not happy with the result of the second exercise? Goto the the labs/reactive-forms/exercise-3 directory and run npm i. When complete, start the application using npm start

Create a custom control for hold the entire form from edit playground modal. This might seem strange, but it does make sense, to extract the editing of a playground from the modal. Enabling you to use it multiple places.

Using the CLI create a custom control called edit-playground-control. Move the template related to the form from the modal to the new controls template.  Next move the form group from the modal to the new control. Just delete the async validator from before.
