The form array

  • An array of abstract controls. Any abstract control - but of the same type.
  • Attach the array to the template using the formArrayName directive
  • Use formControlName directive to attach the individual controls to the array
  • Form array validators has access to all the controls/values in the array. This enables validation across controls in the array. 
  <div formArrayName="emailAddresses" class="form-group flex-wrap">    @for(_ of emailAddressesControl.controls; track $index) {      <input        type="text"        class="col-12 form-control mb-2"        [formControlName]="$index">    }  </div>
