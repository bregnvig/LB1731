The form control

  • A single control. Until we talk about custom controls this is often just an input of some type, a select, a checkbox or a radio button
  • Attach the control to the template using the formControl or formControlName directive 
  • Validators work on this control only 
<input   id="name"   type="text"   class="form-control col-6"   placeholder="Name"   formControlName="name">
<input   id="name"   type="text"   class="form-control col-6"   placeholder="Name"   [formControl]="fg.controls.name">
If anyone in doubt in regards to formControl or formControlName, go back to the top 5 example. What to use? Name or control? Lets see how the name does only produce runtime errors, while control produces compile time errors. Historically you will have a lot of formControlName, but consider start using formControl.
