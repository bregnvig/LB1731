The abstract control - top 5 properties & methods

  • value - the current value of the abstract control. Valid or not
  • invalid or valid - the current validity state of the abstractcontrol
  • valueChanges - a data stream of change events
  • reset - initialize/resets the abstract controls values
  • patchValue - updates the abstract controls values
