Lazy loading

Strategies

RouterModule.forRoot(
  routes, 
  { preloadingStrategy: PreloadAllModules | NoPreloading },
)
Like said before: Eager loading is the default loading strategy, but there can be more to it. RouterModule.forRoot takes a second ExtraOptions arg where preloadingStrategy can be defined. `PreloadAllModules` or `NoPreloading` are provided by Angular. show demo
