Exercise 1 - Add routes to playground app 1/2

  • Goto the the labs/routing/exercise-1 directory and run npm i. When complete, start the application using ng serve
  • Since the app component will host the router-outlet the code in the app component must be moved to a new component. Create a map component using the CLI. Move the content of the app component template into the maps template. Next move content of the app component class into the map component class. This will leave the app component as an empty component class.
  • Create a v14 routing array with two routes. An empty route '' and a route with a placeholder ':id'. Both routes must use the map component.
  • Import these routes in the main.ts
  • Add the router outlet to the app component template. Verify our application loads correctly.
