Exercise 2 - REstrict access with auth guard 1/2

  • Not happy with the result of the first exercise? Goto the the labs/routing/exercise-2 directory and run npm i. When complete, start the application using ng serve
  • LoginComponent & AuthService is already part of the codebase
  • We want to restrict the access to our application. Our users need a place to login so we must setup a new route with path 'login' that uses the LoginComponent. Make 'login' route the first route!
  • Our application should use a functional guards on route that we've defined are restricted. Guard paths: '' and ':id' with a authGuard: CanActivateFn functional guard directly in the app.routing.
  • The functional guard should use the AuthService to either return an Observable<boolean | UrlTree> where the UrlTree will result in a navigation to the 'login' path.
