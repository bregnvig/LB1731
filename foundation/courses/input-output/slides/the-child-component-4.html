The child component

@Component({
  selector: 'app-directly-child',
  template: `
    <p>{{value1()}}</p>
    <p>{{value2()}}</p>
  `,
})
class DirectlyChildComponent {
  value1 = input.required<string>();
  value2 = input<string>();
}

This is the first time we have seen a signal

Notice the () in the template. The value is no longer a simple data type but a signal
