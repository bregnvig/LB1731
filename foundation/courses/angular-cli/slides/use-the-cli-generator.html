Use the CLI generator

Other generate option

# Generate a module
ng g module <path>/<module-name>

# Generates a service
ng g service <path>/<service-name>

# Generates a class
ng g class <path>/<class-name>

# Generates an interface
ng g interface <path>/<interface-name>

# Generates a pipe
ng g pipe <path>/<pipe-name>

The <path> allows you to generate something in a specific folder. E.g ng g service share/my
