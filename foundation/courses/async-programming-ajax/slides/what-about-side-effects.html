What about side effects?

Maybe you need to work with a third party library that doesn't support signals

Example from the leaflet.component.ts

effect(() => {
  const center = this.center();
  const map = this.#map();
  if (center && map) {
    map.setView(latLng(center.lat, center.lng));
    center.zoom && map.setZoom(center.zoom);
  }
});
So when the map is create it will be called. When center changes it will be called
