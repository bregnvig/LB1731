The child component

@Component({
  selector: 'app-directly-child',
  template: `
    <p>{{value1}}</p>
    <p>{{value2}}</p>
  `,
})
class DirectlyChildComponent {
  @Input() value1?: string;
  @Input() value2?: string;
}

The parent component stays the same

Notice we have no () here, as value1 is a simple string
