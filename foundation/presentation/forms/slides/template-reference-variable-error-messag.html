Template reference variable & error messages

Use template reference variable to e.g. show and hide an error message

<div>
  <label for="lastName">Last name</label>
  <input required [(ngModel)]="model.lastName"
    name="lastName" #lastName="ngModel">

  <ngb-alert type="danger" [hidden]="lastName.valid || lastName.untouched">
    Last name is required
  </ngb-alert>
</div>
