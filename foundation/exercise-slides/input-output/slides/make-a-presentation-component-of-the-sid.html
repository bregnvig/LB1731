Make a presentation component of the sidebar

Right now, even though it is a bit simple, the sidebar knows how to get a reference to the playgrounds to display. This makes it a smart component. Again, currently this is kind of simple.

Instead let’s make the AppComponent the smart component. Copy the playgrounds property from the sidebar component to the app component and rename it to appPlaygrounds.

Next delete the assignment of the playgrounds property in the sidebar component and prefix the property with input. Make it required

Remember to import it from @angular/core module. If you save now, no playgrounds are shown😲

Next step is to assign the sidebars playgrounds property using the property data binding syntax, used in the parent → child scenario.

Now the sidebar has no knowledge of how the playgrounds were fetched👌
