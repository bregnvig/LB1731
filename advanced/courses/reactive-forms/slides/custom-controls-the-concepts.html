Custom controls - the concepts

  • You either add functionality to a simple input field. E.g the address element from before
  • Or you group the input fields the belongs together.. E.g the address form group from before
  • Propagate changes - When a change occurs in the custom control the form that uses this custom control must be notified
  • Write value - When a control is to be initialized with a value we write the value to the control, using either patchValue or reset
  • Enable/disable - when the parent form want a control enabled or disabled the custom control is notified and should handle the event.
  • Marked as touched - When the inner controls are touched, the customer control must propagate this to the parent.
What you write is what you propagate! Simple as that! Always do that! Marking as touched is all about CSS classes
