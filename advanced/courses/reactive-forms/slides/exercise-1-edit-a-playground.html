Exercise 1 - Edit a playground

Goto the the labs/reactive-forms/exercise-1 directory and run npm i. When complete, start the application using npm start

Open the edit-playground-modal component class.

Start by creating a form group. You should use the injected form builder. The form group must consist of three controls; name, description & addressDescription

Attach the form group and the controls to the template using the formGroup and either formControlName or [formControl] directive.

Next reset the form with the value of the playground in ngOnInit.

Change the save method to close the dialog with the content of form. Make sure the original playgrounds position is part of the save method call. If not you will lose it!

Try to edit a playground, click OK and then verify that the list of playgrounds is being updated with the new playground data. (Will be lost at reloading)
