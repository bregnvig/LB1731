Exercise 2.2 - Add custom validator

Continuing with the exercise, you need to add your own custom validator.

Make sure either description or addressDescription is filled out.

The custom validator should return either null or { requiredOr: ['description', 'addressDescription'] }

Remember that the returned ValidationErrors object is just something I dreamt up. This is not some specific format. It is just a Record<string, any>.

Try to edit a playground and notice that the OK button is disabled, when you remove description and address description.
