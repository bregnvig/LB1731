Form validation

  • Attach one or more validators to any kind of control
  • A validator is just a function - therefore easy to test😃 Have you seen Johannes' unit test module? If not - go sign up!👍
  • Receives a single parameter, of type abstract control, to perform the validation on.
  • Returns null for passed validation.
  • Returns ValidationErrors which is just a Record<string, any> for a failed validation
  • Lots of built-in validators. Check Validators from @angular/forms
  • errors is really the top 6 property on an AbstractControl. Use this property to create meaningful errors messages
  • The CSS class ng-invalid will automatically be added and removed from the control by the Angular framework 
Talk briefly about validators are directive in template driven forms errors consists of the errors accumulated by the different validators
