Exercise 2.3 - Add async custom validator

Continuing with the exercise, we should add our own async custom validator.

So create an async validator, that makes sure that the playground name is unique. You will need to inject the PlaygroundService to get this to work.

Return an observable of type null or ValidationErrors

You will need to compare the value of the name control with the existing playground names, but you must also make sure you are not comparing the controls value with the playground instance variable. I.e the playground you are currently editing.

Try to edit a playground and reuse a name from another playground. Notice that the OK button is disabled when the name is not unique.
