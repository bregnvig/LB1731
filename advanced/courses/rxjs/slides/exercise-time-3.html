Exercise time

  1. In the same folder as before, labs/rxjs
  2. Run ng serve, if not already running

  3. Go to app.component.ts

  4. Use the filter operator to filter playgrounds$ from PlaygroundService in the app component if the response is empty or an empty array

  5. Extract the filter function into a custom operator using the pipe function to build a new operator. Call the custom operator withLength and place it in utils/rxjs-utils.ts

  6. Use the custom operator in the app.component.ts
this exercise aims to deepen your understanding of how to work effectively with observables and custom operators in real-world scenarios. Hands-On Practice: You'll apply the filter operator to process data from an observable (playgrounds$). This helps solidify your knowledge of filtering streams based on specific conditions, like checking if the data is empty. Custom Operator Creation: By extracting the filtering logic into a custom operator (withLength), you'll learn how to encapsulate reusable logic, making your code more modular and easier to maintain. Practical Application: Finally, you'll integrate the custom operator back into your component, which gives you practical experience in enhancing your code's readability and functionality by using custom operators.
