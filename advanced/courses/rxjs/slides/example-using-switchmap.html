Example using switchMap

With switchMap

interval(1000).pipe(
    switchMap(() => this.service.getSomething())
).subscribe(something => this.something = something);

Without switchMap - An anti pattern🤬 

interval(1000).pipe(
    map(() => this.service.getSomething())
).subscribe(something$ => {
  something$.subscribe(something => this.something = something)
)

What to do with all these subscriptions?

A classic example of using switchMap is when you use this.route.params.pipe(switchMap(({id} => this.service.getById(id)))
