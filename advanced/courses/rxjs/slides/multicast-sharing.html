Multicast/sharing

Observables behaviour are unicast by default. I.e not shared.

When would you want to share? Expensive backend calls. If data rarely changes / historical data. If you subscribe to it multiple places using the async pipe

 

Use share, shareReplay to turn the observable into a multicast.

Not shared means that every new subscriptions will go from the top of the chain. It might result in a e.g network request. Do I share in the service or in the client? It depends - If the service knows that data is fresh, it might as well share it. Otherwise the correct place to share is often to client. We will see examples soon
