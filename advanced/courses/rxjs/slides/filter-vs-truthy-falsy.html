Filter vs. truthy / Falsy

export const truthy = <T>() => pipe(filter(x => !!x);
export const falsy = <T>() => pipe(filter(x => !x);

// Only when there are result from the backend
this.service.getPlayground(id).pipe(
  truthy()
).subscribe(playground => this.name = playground?.name);

// Same thing, using filter
this.service.getPlayground(id).pipe(
  filter(playground => !!playground)
).subscribe(playground => this.name = playground?.name);
Here we're using custom operators, truthy() and falsy(), to filter streams based on truthy or falsy values. Simplifies Reuse: These operators makes our code more reusable and expressive by encapsulating common filtering logic. Comparison: Both the custom truthy() and a regular filter achieve the same result, but truthy() makes the intent clearer, improving readability. Like this you can too abstract and simplify repetitive tasks, making your code cleaner and easier to maintain!
