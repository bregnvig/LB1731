First Subscriber: Receives all events (1-4) as it subscribes from the start. Second Subscriber: Subscribes later, only receiving events 3 and 4. With share: Ensures all subscribers share the same execution of the observable, preventing duplicate emissions and side effects. So use this when you want to wait for the next event before receiving an event
