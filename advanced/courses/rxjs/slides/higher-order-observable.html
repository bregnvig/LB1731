Higher order observable😵

  • A higher-order observable is just a fancy name for an operator that emits an inner observable

  • Is a flattening operator

    • So if a map operator returns an observable use a higher order observable

  • Subscribes so you don’t have to!

We talked about this at the Angular Foundation Think of it as an operator that emits another observable. It’s mainly used to flatten observables. Key point: If map gives an observable, use a higher-order one. Bonus: It auto-subscribes, simplifying your code!
