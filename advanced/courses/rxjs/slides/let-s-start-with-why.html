Let's start with WHY

If we don't, we'll have memory leaks!

 

 

But how?

There are several ways

  1. Use the first() operator - not recommended🤨
  2. Turn the observable into a Promise using firstValueFrom() - not the rxjs way!
  3. Use the async pipe
  4. takeUntilDestroyed() from Angular
  5. Using the npm package @ngneat/until-destroy 
interval(1).subscribe(no => {
  this.nos.push(no);
})

If you have the above code in your component and your component is destroyed you have a memory leak!

But what if observable is completed you ask? Well then you don't a memory leak. But do you really know whether it's complete or not?🤔
