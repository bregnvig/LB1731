Create routing module

const AppRoutingModule = RoutingModule.forRoot([
  {
    path: '',
    component: RoutingComponent,
  },
]);
const AppRoutes: Routes = [
  {
    path: '',
    component: RoutingComponent,
  },
];

Since v14 standalone

Before v14 standalone

@NgModule({
  imports: [
    BrowserModule, 
    AppRoutingModule
  ]
})

In app.module

bootstrapApplication(AppComponent, {
  providers: [
    provideRouter(AppRoutes),
    ...
  ]
})

In main.ts or app.config.ts

Creating a routing module i quite simple. We just need to use either forRoot or forChild. Talk about forRoot and forChild., Talk about Splitting routes into different files for better overview. So since v14 we no longer need the module. Since v.15.2 we can automatically migrate to standalone
