One last thing about PROVIDING

providers: [
  {
    provide: PlaygroundService,
    useClass: PlaygroundService, 
    multi: true
  },
  {
    provide: PlaygroundService,
    useClass: AarhusPlaygroundService, 
    multi: true
  }
]

In this case you might receive an array of services😵

This is primarily used by the framework, but you can of course also use it. Used when creating custom control. E.g. when using the APP_INITIALIZER
