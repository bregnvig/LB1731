ExerCISE - Use an InjectionToken

If not happy with the solution to exercise 1? Then goto the the labs/di/exercise-2 directory

Now that we know how to provide a string, let's change the service playgrounds.service to have the URL injected.

Because there is really no reason to have two identical services, when the only difference is an URL.

So add an InjectionToken, without a default implementation. Assign the injection token to a constant  called PLAYGROUNDS_URL.

Now provide the PLAYGROUNDS_URL in the main.ts using useValue. Create a new environment variable, in both environments, called playgroundsURL use the urls from the existing services.

Finally you need to update the PlaygroundService to have the URL injected and used.

You can now delete the aarhus-playground.service.ts if you feel like. That way you are also sure you are not referencing it anywhere.

Try running both npm run copenhagen and npm run aarhus to see that it works
