1. concept - An injector

😄

Angular looks for dependencies within injectors. Angular creates these injectors. One application wide, zero or many other injectors An injector is just a map with a key of type InjectionToken and a value of whatever Services are created when requested for the first time. Goto Without DI and reload - notice how a service is being created. Then goto With DI. A new service is being created. Going back, will create yet another service - but that is because we are not using DI. Now returning to With DI will not create a new service - as the service has already been created There are at least one injector. The application wide injector. maybe many more
