APP_INITIALIZER - BUILT-IN INJECTION TOKENS

[{
  provide: APP_INITIALIZER,
  useFactory: initializeApp,
  deps: [HttpClient, TranslationService],
  multi: true
}]

Provide a factory function to be executed before the application is made available. Notice the factory function must return a function!

 

If the function returns an observable initialization is not complete, until the observable is complete. Deprecated - use provideAppInitializer

const initializeApp = (http: HttpClient, translate: TranslaterService): Observable<void> => function() {
  return this.http.get('assets/translations.json').pipe(
    tap(translation => translate.setTranslation(translation))
  );
}
Notice the multi. So either use first, if you are 100% sure the stream will complete, or use a promise
