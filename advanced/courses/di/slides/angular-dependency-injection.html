angular Dependency injection💉

  • Uses inject function
  • Or use the constructor injection pattern
  • Dependencies are singletons (Within the scope of injector)
  • Any type of dependency can be injected. Not just classes
  • A dependency must to be provided
  • Circular dependencies not possible👎

 

constructor pattern. Meaning we define our dependencies in the constructor. Since v16 both as parameters or using the inject() function
