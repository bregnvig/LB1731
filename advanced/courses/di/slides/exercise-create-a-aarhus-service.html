ExerCISE - Create a Aarhus service

Goto the the labs/di directory

Create an aarhus-playground.service.ts by copying the  existing playground service.

Change the URL to point to the assets/aarhus.json. The aarhus service should NOT have the providedIn: 'root'

Open the environment.ts and add a property location. Give it a value of 'copenhagen'. Next up open the environment.aarhus.ts and add the same property with a value of aarhus

Use a factory provider and the location property from the environment to decide which service to create, using new, and return from the factory method in the main.ts.

You should be able to npm run copenhagen and npm run aarhus at the same time. Verify that you see different playgrounds
