​Seamless Integration with Observables

Easily create outputs that emit values from observables with outputFromObservable().​​

Outputs got the same treatment. output() replaces @Output and EventEmitter. It is stable since v19. You declare it as a field, like input, and call emit to send a value. It is not a signal. It is an event, so there is nothing to read. If you already have an observable, outputFromObservable turns it into an output.
