Exercise 2 - Sidebar list item

Let's create a SidebarListItemComponent. In a new terminal in labs/signals/exercise-2, run:

npx ng g c sidebar/sidebar-list-item -t -s

-t -s: inline template and inline style

The purpose is of course to display a single playground in the sidebar.  So let's create 3 input signals

  • playground
  • active
  • location

Move the button element from the SidebarComponent to the new component. Use the new properties to display a playground. Use the new component in the SidebarComponent template. Where should I place the click listener?

Next, pull one row of the sidebar out into its own component. In a new terminal in labs/signals/exercise-2: npx ng g c sidebar/sidebar-list-item -t -s. That gives an inline template and inline styles. It gets three inputs: playground, active and location. Move the button from the sidebar into it. Ask the room where the click listener goes. The answer: in the sidebar, on <loop-sidebar-list-item>. The sidebar owns the selection and emits selected, so the list item only displays.
