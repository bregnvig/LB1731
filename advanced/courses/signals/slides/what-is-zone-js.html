What is Zone.js?

  • It "monkey patches" events in the browser
  • It makes change detection works seamlessly in your Angular application😁
  • It detects when a change might have occured. And it might not🤔
  • It requires additional JS code to be executed🙄
Monkey-patch a way to extend or modify the runtime code of dynamic languages (e.g. Smalltalk, JavaScript, Objective-C, Ruby, Perl, Python, Groovy, etc.) without altering the original source code Zone.js modifies/monkey patches native browser APIs such as setTimeout, setInterval, addEventListener, and even promises. Zone.js intercepts these asynchronous operations, track when they start and finish, and notify Angular when they complete. Seamless change detection: Zone.js integrates with Angular's change detection mechanism by ensuring Angular knows when to check for updates in the UI Has a change even occured: Zone.js doesn't precisely know if a state change has happened; it just knows that some asynchronous operation has finished. Which can be costly for your app. Additional: Adds an additional overhead in form of extra javascript code to your app. Also might induce performance reduction because of above reasons.
