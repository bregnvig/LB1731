Effect Cleanup

@Component({...})
export class SearchComponent {
  query = signal('');

  constructor() {
    effect(onCleanup => {
      const query = this.query();
      const timer = setTimeout(() => this.search(query), 300);
      // Before the next run, and when it's destroyed
      onCleanup(() => clearTimeout(timer));
    });
  }
}

Cancel what the previous run started: a timer, a request, a subscription. Here: only search when the user stops typing.

Type fast: each keystroke clears the previous timer, only the last query is logged. Cleanup is for cancelling, not remembering the previous value (that's linkedSignal's long form). v22: debounced(signal, 300) does this (experimental); resources cancel their own requests. An effect can clean up after itself. It gets an onCleanup function. What you register runs before the next run and when the effect is destroyed. Use it to cancel what the previous run started: a timer, a request, a subscription. Here it is a debounced search: every keystroke starts a 300 ms timer, and the next keystroke clears it.
