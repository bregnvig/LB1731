"Store"

  • A store is a concept. It store state
  • Provide the same way as a Angular service
  • Remember that injectors exists on different levels
If a service is provided in root, the service state becomes application wide state. If it is provided in a component it will die along with the component If provided a in route, it will be created at initial load of the route, never die, but only be accessible within this route. So again the initial state is only be set once.
