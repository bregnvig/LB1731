Local state / Component HIERARCHY

  • Provided on component level
  • Shared across the entire component hierarchy
  • Exists for the entire lifespan of the component. 
  • Is dynamic and can change during its lifespan
Mostly likely we would use a DI service to store the state. Unless there is a direct parent-child relationship where the child e.g is a presentation component. Every time a component dies its state dies with it. Every time a component is created, its initial state is created with it. Which is also the reason application state is only initialized once, as the application is only initialized once.
