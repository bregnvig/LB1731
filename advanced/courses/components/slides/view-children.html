View children

  • Injected into the component by the framework
  • Uses the viewChildren (v17.2) signal query or the @ViewChildren decorator
  • Injected by type or by template reference variable name(s)
  • viewChildren injects a signal of a read-only array of matched elements.
  • @ViewChildren injects a QueryList that is ready in the ngAfterViewInit life cycle method. This can be used to listen for changes.
