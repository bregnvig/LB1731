How does Angular detect changes?

Short answer zone.js

 

zone.js will override:

  • all browser events (click, mouseover, keyup, etc.)
  • setTimeout() and setInterval()
  • Ajax HTTP requests

If zone.js does not override a specific part of the browser API, change detection will not happen. E.g events in an observable and IndexedDB callbacks. (You can do it manually)

You can now opt out of zone.js by initializing you application provideZonelessChangeDetection()
