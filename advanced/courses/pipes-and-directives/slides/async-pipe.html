Async pipe

<p>
  {{ date$ | async | date: 'HH:mm:ss' }}
</p>

<!-- 18:12:01 -->
<!-- 18:12:02 -->

Let Angular handle subscribing and unsubscribing for you.

Also works with OnPush change detection strategy, as the async pipe will mark your component for change detection

date$ = interval(1000).pipe(map(() => new Date()))

So avoid memory leaks and write less code!🤯

If you subscribed to this observable, you would need to unsubscribe when destroying the component. Using async you dont have to do anything. Are we all clear about the marking for change detection?
