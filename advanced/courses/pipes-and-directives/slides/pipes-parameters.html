Pipes - parameters

A pipe may accept one or more parameters, in addition to the input value

Parameters are added after the pipe name, separated with colon

<p>Today is {{ today | date: 'dd-MM-yyyy' }}</p>
<!-- Today is 04.01.2022 -->
<p>Today is {{ today | date: 'dd-MM-yyyy' : 'Europe/Copenhagen' }}</p>
// From the date pipe
transform(value: Date, format?: string, timezone?: string, locale?: string): string | null;
Parameters can be constants, as in this example, or they can be bound using data binding
