Exercise 4

  • Not happy with the result of the previous exercise? Go to the the labs/pipes-directives/exercise-3 directory and run npm i. When complete, start the application using ng serve
  • Lets create an is-in-role directive without the else option.
  • We should use this directive to determine whether or not the edit button should be visible in the sidebar
  • Use the Angular CLI to create the directive in the directive folder
  • There is already a pre-cooked auth service that you can inject into the directive. Remember the other two required dependencies!
  • Using the isInRole$ method from the AuthService to determine whether or not the edit button should be visible. Since a persons role can change we need to react to the changes we get from the "is in role" observable.
  • There is a button in the upper left of your browser. Clicking it will switch between anonymous and admin. Make sure clicking this button will change your UI
  • You should unsubscribe from the observable, when the directive is destroyed
