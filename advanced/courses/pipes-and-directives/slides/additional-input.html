Additional input

It is possible to have additional input

Let's create an else option

@Input()
set loopIsInRoleElse(value: TemplateRef<any>) {
  this.elseTemplate = value;
  this.updateView();
}

<div class="col-4">
  <span *loopIsInRole="'anonymous'; else notAnonymous">I'm anonymous</span>
  <ng-template #notAnonymous>I'm someone</ng-template>
</div>
The input property must be prefixed with the selector name Show the example
