Is the test any good? The oracle

The oracle is the part of a test that decides pass or fail: the expect.

A weak oracle passes for almost any code:

• asserts the function's own output
• toBeTruthy(), length > 0
• toHaveBeenCalled and nothing else

  it('should return a result', () => {
    // Act
    const result = filterPlaygrounds(playgrounds, 'christianshavn');
    // Assert
    expect(result).toBeTruthy();
    expect(result.length).toBeGreaterThan(0);
  });

  it('should return the filtered playgrounds', () => {
    // Act
    const result = filterPlaygrounds(playgrounds, 'christianshavn');
    // Assert
    expect(result).toEqual(filterPlaygrounds(playgrounds, 'christianshavn'));
  });

Would this test fail if the code were deleted?

If not, it is not testing anything. A green weak test is worse than no test: it looks like safety.

Source: Banik, Chowdhury and Shamim, "All Smoke, No Alarm: Oracle Signals in Agent-Authored Test Code", arXiv:2606.18168, June 2026. 86,156 test-file patches from five coding agents: 80.2% had weak or no explicit oracle signals. (It counts oracle signals in patches, not bugs caught.)

Look at the oracle: the expect, the part that decides pass or fail. On the right is a spec for filterPlaygrounds. The first test checks the result is truthy and not empty. The second compares the function to itself. Both would pass if filterPlaygrounds returned anything non-empty, and the second would pass even if it returned garbage. The question to ask of every test, yours or generated: would this test fail if the code were deleted?
