Unit of work: entry point to one noticeable end result (Roy Osherove, The Art of Unit Testing; 3rd edition, Manning 2024, with JavaScript/TypeScript examples). Three outcomes: return value, state change, third-party call. Check the outcome, not the steps. A unit is not a class and not a file. It is everything that happens from the moment the test calls an entry point until something observable comes out. Osherove names three kinds of end result. The entry point returns a value or throws. It changes state that you can read back afterwards. Or it calls something you do not own, such as the network. How you test it depends on the kind, so the next slide gives you one playground example of each. You assert on the outcome and ignore the steps in between.
