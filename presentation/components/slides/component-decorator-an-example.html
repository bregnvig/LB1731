@Component decorator - An example

@Component({
  selector: 'app-outer',
  template: `
    <div>
      <p>I'm the outer component</p>
      <app-inner></app-inner>
    </div>
  `,
  imports: [InnerComponent],
  styleUrl: './outer.component.scss'
})
export class OuterComponent { ... }

Prior to v17 standalone: true was required to make component standalone. Use standalone: false, if the component is not standalone
