The child component - transform the value

@Component({
  selector: 'app-intercept-child',
  template: '<p>{{value}}</p>'
})
class InterceptChildComponent {
  
  #value = '';

  @Input()
  set value(value: string) {
    this.#value = value.toUpperCase();
  }

  get value(): string {
    return this.#value;
  }
}
The parent interacts with the child the same way as when assigning a value directly
