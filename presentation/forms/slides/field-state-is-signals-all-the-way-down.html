Field state is signals all the way down

// The value - the whole model, or one field
form().value()
form.firstName().value()

// Validity
form().valid()
form().invalid()
form().errors()

// Has the user been here yet?
form().touched()
form().dirty()

// Every field exposes the same API
form.height().invalid()
form.height().errors()

Everything is a Signal, so the template just reads it - no valueChanges subscription
