Depending data sources - use computed

What if I have depending data source. E.g. I need my current geo location and the playground's position to calculate distance

@Component({
  selector: 'app-playground',
  template: `
	{{ playground()?.name }} is {{ distance() }} away
  ` 
})
export class PlaygroundComponent {
  playground = input.required<Playground>();
  location = input.required<Coordinate>();
  
  distance = computed(() => {
    const playground = this.playground();
    const location = this.location();
    
    if (playground && location) {
      return `${getDistance(location, playground.position)}m`;
    }
    return 'unknown distance'
  });
}
Every time either playground or location change this computed will be called again.
