How to provide a dependency since v22

@Service()
export class RandomService {
  …
}

Provided in root. As easy as that!

@Service({ autoProvided: false })
export class RandomService { … }

export const appConfig: ApplicationConfig = {
  providers: [RandomService]
};

Or opt out, and provide it in app config

@Service() is provided in root by itself. We'll talk more about where services are provided in the advanced courses
