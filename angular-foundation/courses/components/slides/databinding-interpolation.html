Databinding interpolation

Use {{ VALUE }} to write to the screen
<ul>
  <li>Property string: {{myString}}</li>
  <li>Property number: {{myNumber}}</li>
  <li>Property object: {{myObject.someProperty}}</li>
  <li>Property null: {{myNull}}</li>
  <!--<li>Property null - will fail: {{myNull.someProperty}}</li>-->
  <li>Property null - wont fail: {{myNull?.someProperty}}</li>
  <li>Simple method: {{simpleMethod()}}</li>
  <li>Parameter method: {{parameterMethod('world')}}</li>
  <li>Simple expressions: {{isCreating ? 'Create': 'Update'}}</li>
  <!--<li>New object - will fail {{new Date()}}</li>-->
</ul>
