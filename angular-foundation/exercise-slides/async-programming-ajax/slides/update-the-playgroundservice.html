Update the PlaygroundService

Now that the http client service is accessible throughout the application, let’s inject the HttpClient service into the playground service.

Since we know an observable is only a blueprint until subscribed, let’s set up the http call in the constructor. Assign the observable returned from the http get to an instance variable called playgrounds$ of type Observable<Playground[]>

We can get the playgrounds from either  copenhagen.json or aarhus.json

Change the getPlaygrounds to return playgrounds$, and of course the return type of the getPlaygrounds method.

And since the playgrounds rarely changes turn our observable into a multicast, by using the
shareReplay(1) operator.
