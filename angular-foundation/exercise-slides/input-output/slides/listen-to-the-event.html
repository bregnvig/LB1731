Listen to the event

Going back to the app component, we need to listen for this event.

We can only listen for events on the child elements that emit them, so two siblings cannot communicate directly using event emitters.

So create a method called playgroundSelected in the app component. When called it should set a property called playground to the given value.

Lastly update the app template to listen to the event from the sidebar component and call the method.

Before proceeding to the next exercise try to log out the selected playground using console.log()🤓
